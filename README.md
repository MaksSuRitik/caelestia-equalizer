# Standalone Music App

Это независимое приложение-каркас, отвязанное от оболочки.

## Как запустить на CachyOS:
1. Установи PyQt6: `sudo pacman -S python-pyqt6`
2. Запусти: `python main.py`

## Интеграция твоих файлов:
Твой `MusicPopup.qml` использует кастомные кнопки (`ClickButton`, `Dropdown`, `Draggable`). Тебе нужно скопировать эти файлы из оригинальной темы (из папки `reusables`) в папку `ui/` этого проекта, иначе QML их не отрисует.
После этого подключи свой попап в `main.qml`.
